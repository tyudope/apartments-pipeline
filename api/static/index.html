Flow

Steps

1 · Extract

pipeline/extract.py
  • Copies the month's source CSV to data/raw/month=YYYY-MM/, byte for byte.
  • Hashes source and raw with SHA-256; identical checksum ⇒ skip, new content ⇒ re-land.
  • Fails loudly if the source file for the month is missing.

2 · Transform

pipeline/transform.py
  • Schema guard: refuses to run if the raw columns differ from the expected 28.
  • Normalizes: snake_case names, yes/no → boolean, lowercased text, nullable ints; derives price_per_m2 and month_key.
  • Routes bad rows to a rejects set with a reason (area, price, ppm², rooms, floor, build year, coordinates); first failing rule wins.
  • Drops duplicate ids within the month, then overwrites the silver Parquet partitions.

3 · Load

pipeline/load.py
  • Ensures the schema exists, then runs the whole month in one transaction.
  • dim_month: insert, ON CONFLICT DO NOTHING.
  • fact_listing: COPY into a temp table, then upsert ON CONFLICT (id, month_key).
  • rejects: delete the month, insert the month; logs inserted/updated counts to run_log.

4 · Checks

pipeline/checks.py
  • Six rules: rows present, no null keys, unique id, no orphan cities, reject rate ≤ 10 %, volume within ±50 % of previous month.
  • Every check writes a PASS/FAIL row to run_log.
  • Any failure raises; run.py then quarantines the month by deleting it from fact_listing. Raw and silver stay for diagnosis.

5 · Serve

api/main.py
  • FastAPI reads Postgres with psycopg; each analytical endpoint is one SQL file in sql/questions/.
  • /health is OK only when the latest run of every check passed.
  • Unknown city keys return 404; database down returns 503.
  • Serves this page and vendored Chart.js from /static.

Data model (schema dw)

ObjectKeyWhat it holds
dim_citycity_key15 cities: display name and voivodeship.
dim_monthmonth_keyYear, month, quarter, first day.
fact_listing(id, month_key)One listing as observed in one month: area, rooms, floor, build year, location, flags, price, price_per_m2.
v_listing_latestidView: DISTINCT ON (id), last month observed. One row per flat for pricing questions.
rejects—Rows the transform refused, with reject_reason. Replaced per month.
run_logrun_idOne row per step and per check: month, passed, value, ran_at.

Grain: one row per listing per month observed. The same flat seen in three months is three observations of the market, not a duplicate.
